# Missions — 11th edition matched play pack

⚠ **Content not populated yet.** The environment that generated this repo
cannot reach wahapedia.ru, and mission scoring conditions must be exact — no
approximation from memory. The four files below are structured templates to
fill from Wahapedia once, then keep in sync after each GW update.

## Files

- `primary-missions.md` — one section per primary mission card: name, scoring
  window (command phase / end of turn), exact VP conditions and caps.
- `mission-rules.md` — one section per mission rule card, verbatim effect.
- `deployments.md` — one section per deployment map: name, zones description,
  objective placement.
- `secondary-missions.md` — one section per secondary card: fixed/tactical,
  exact scoring conditions, when scored, discard rules.

## How to populate

1. Open the current matched play pack section on Wahapedia (11th edition,
   the most recent "Chapter Approved" pack).
2. For each category, copy the card texts into the matching file, one `##`
   section per card, keeping the exact wording of scoring conditions.
3. Note the pack name and copy date at the top of each file.

The format (flat markdown, one `##` per card, no tables) is deliberate: these
files are meant to be pasted whole into an LLM context during a coaching
conversation, so the model can quote exact scoring conditions.
