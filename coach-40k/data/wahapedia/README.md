# Wahapedia data export

⚠ **No data is committed yet.** The environment where this repo was built cannot
reach wahapedia.ru (network policy + Cloudflare), so the CSV files must be
downloaded from a normal machine.

## How to populate / refresh

From the repo root, on any machine with normal internet access:

```
python scripts/update_data.py
```

That downloads the full 11th-edition export (pipe-delimited UTF-8 CSVs) from
`https://wahapedia.ru/wh40k11ed/<file>` into this folder and writes
`EXPORT_DATE.txt` with the download date. Commit the result.

If the script fails (Cloudflare challenge), download these files manually from
your browser — URL pattern `https://wahapedia.ru/wh40k11ed/<name>` — and drop
them here. The engine strictly needs the first six; the rest are context data
kept for future use:

Required by the engine:
- `Datasheets.csv`
- `Datasheets_models.csv`
- `Datasheets_wargear.csv`
- `Datasheets_keywords.csv`
- `Datasheets_models_cost.csv`
- `Factions.csv`

Nice to have:
- `Datasheets_abilities.csv` (shown as reminders next to results)
- `Datasheets_unit_composition.csv`, `Datasheets_options.csv`,
  `Datasheets_leader.csv`, `Abilities.csv`, `Stratagems.csv`,
  `Enhancements.csv`, `Detachment_abilities.csv`,
  `Datasheets_stratagems.csv`, `Datasheets_enhancements.csv`,
  `Datasheets_detachment_abilities.csv`, `Source.csv`, `Last_update.csv`

## Format notes

- Separator is `|` (vertical bar), files are UTF-8 (some with BOM), and each
  row ends with a trailing `|`.
- `description` fields contain HTML; weapon keywords appear inside the wargear
  `description` column.
- Files are regenerated by Wahapedia within ~15 min of any site update, so
  re-running the script after a GW balance dataslate is enough to stay current.
